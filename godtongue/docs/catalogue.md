# The Studio Morgana catalogue

_Generated by `node tools/catalogue.mjs` from `core/catalogue.js`, the live registry, the engines and the app's API. Do not edit by hand._

Everything the platform can make, every property each part has, what the renderer does with it, and the words a writer uses to reach it today. The language is built to cover this list; `test/run.js` fails when the compiler or the renderer uses a property that is not listed here.

## How a piece is built

1. **Source.** A piece is written in godtongue: plain sentences (`Let there be …`, `Make …`, `Give …`). See `docs/english.md`.
2. **Document.** The compiler turns the source into a Card Document: plain JSON, the only contract between the language and the renderers. Every property below is a field of it.
3. **Render.** An engine reads the document. In the app, `web` renders in the browser (WebGL2, live light) and exports PNG and MP4; `svg` exports flat vectors.
4. **App.** Studio Morgana stores pieces, versions and rendered outputs, and the model writes and edits sources (the HTTP API at the end).

The craft operations (emboss, engrave, deboss, etch, plate, foil, inlay, spray, print, illustrate, mix, sign, reveal, caption, place) keep their own first word by design, so they count as "yes".

| `adjust`, `filter` | An adjustment layer: changes everything already painted under an area. blurred 12 (frosted glass), brightness 1.1, contrast 1.2, saturation 0.6, hue 40, grayscale, sepia, inverted. Write it after the things it should change. |
| `vignette` | Darken (or tint) the edges of an area, leaving its middle clear: an amount from 0 to 1 (default 0.5), optionally "in #colour". |
| `grain`, `noise` | Film grain over an area, for texture: an amount from 0 to 1 (default 0.25). "coarse" makes bigger grains. |
| `stroke` | A flat outline round an area, outside its edge: "stroke the title in #ffffff, 6 wide." (Without a colour, "stroke the petal, 3 wide" draws a shape as a line, like "hollow".) |
| `shadow` | A soft drop shadow under an area. Write it before the steps that colour the area, so the area sits on its shadow. Defaults: 10 down, blur 18, black, 45% opacity. Add "inside" for an inner shadow (written after the colour), which makes the area look cut in. |
| `glow` | A glow of light round an area (outer glow). Write it before the steps that colour the area. Defaults: white, 30 wide, strength 1. |
| `inlay` | Engrave and fill with enamel in one go. |
| `outline` | Engrave a ring around an area and fill it (default niello, 6 wide). |
| `emboss`, `raise` | Raise an area. Height in mm (default 0.12); "soft 0.7" rounds it. |
| `deboss`, `press`, `sink` | Press an area down. Depth in mm (default 0.04). |
| `etch`, `frost` | Frost or matte-etch an area. |
| `spray` | Spray a coat: gloss, candy, glitter, metalflake, pearl, chameleon or matte. "in" takes colours. |
| `print` | Print a photo or illustration into an area (default: the window); printed in a shape, the photo fills that shape. Adjust it: duotone #1b1145 and #ffb347, blurred 6, brightness 1.2, contrast 1.1, saturation 0.5, hue 40, grayscale, sepia, inverted, 70% opacity, multiply. "on foil" prints see-through onto metal. |
| `illustrate` | Cloisonné: turn an illustration into flat enamel cells with metal wires. |
| `write`, `type`, `letter` | Set words in a font. Defaults: Bodoni Moda, size 48, centred. Several lines: put \n in the words, or wrap with "600 wide"; "leading 1.2" sets the line spacing; "aligned left" or "aligned right"; "uppercase"; "tracking 4". "curved 400" sets the words on an arc of that radius (negative curves the other way). Placed by words: "in the sticker", "in the cover, at the bottom left, 120 in", "at the top right" (the page, inside the margin), "under the heading, 40 apart", "beside the play, 16 apart". "as a heading" uses a style made with "Let a heading be …". Several words at once give one label each: Write "a", "b" in each swatch. In a table: Write "1", "Lanterns" in the next row of the playlist. |
| `sign` | A script signature fitted to a spot. Defaults: Herr Von Muellerhoff, 620 wide, size 250, near the bottom. |
| `draw`, `grow`, `add`, `scatter`, `carve` | Draw a generator as a named layer: bezel, rule, band, ironwork, studs, jewels, rims, beads, vine, dots, crosshatch, damask, rays — or a path, or a drawing (@sketch.svg). |
| `move`, `shift`, `slide` | Move elements: "to 620 900" (its centre), "by 10 -20", or "up by 40". |
| `turn`, `rotate`, `spin`, `tilt` | Turn elements by degrees, round their centre (inside a definition: round 0 0) or "around x y". |
| `scale`, `resize`, `grow-by`, `shrink` | Scale elements: "by 0.6", or "by 1.2 0.8" for width and height separately. |
| `flip` | Flip elements in place: left to right, or "upside down". |
| `mirror` | Add a mirror image, making the element symmetric: across a vertical line (default) or "horizontally". "at 620" sets the line. |
| `copy`, `repeat`, `duplicate` | Copy elements: "5 times around 0 0" (a ring), "4 times, 120 apart" (a row), "6 times, 60 apart, 4 rows" (a grid), or once with changes. A loop: "repeat 6 times as: … end." runs the statements inside six times with $n counting 1 to 6 and $i counting from 0 (use them in sums: "(40 * $n) big"); what each pass draws is named orbit-1, orbit-2, … and "the orbit" means all of them ("scale 0.6, turn 36, called inner"). |
| `hollow` | Draw elements as lines instead of solid: "4 wide". |
| `solidify`, `make-solid` | (the opposite of hollow; also "fill it.") |
| `dash` | Turn lines into dashes: "18 on 12 off". |
| `group`, `join`, `combine` | Gather elements into one: "group the wings and the keel as plane." |
| `align`, `line-up` | Line shapes and text up by their edges or centres: left, right, top, bottom, centre (left to right) or middle (top to bottom). Several things align to the group they make; one thing aligns to the canvas. "20 in" keeps a margin from the canvas edge. |
| `distribute`, `space` | Space three or more shapes or texts evenly between the first and the last: "horizontally" (default) or "vertically". "40 apart" sets the gap instead. |
| `place`, `put`, `stamp` | Place a defined object (see "define a … as:"), with its settings: "place a rose at 620 900, size 90, petals 7, turned 15." Several: "place 3 roses from 300 1300, 160 apart." |
| `create`, `start` | Start a room: its width (west to east), depth (south to north) and ceiling height, in metres. |
| `make`, `paint`, `finish` | Give a surface its material or colour: the floor, the walls, the ceiling, the skirting, the window frames. |
| `cut` | Cut a window or a door into a wall. Windows bring daylight in. |
| `place`, `put`, `lay`, `hang`, `add` | Place a piece: a sofa, armchair, coffee table, rug, art or pendant. Say where with "against the … wall", "in front of …", "facing …", "over …", "under …" or "at e n". On a stage, a card file goes on as one element: "place a card called ticket from @ticket.gt at 540 900, scale 0.6." Objects: "place a rose at 620 900." |
| `photograph`, `shoot` | Take a still: where the camera stands (e n, and eye height), what it looks at, and the lens. |
| `take` | Take a 360° panorama from a spot in the room (metres east and north, and eye height). |
| `walk`, `move` | A walk-through: the camera walks from one place to another (through any others), at eye height, eased in and out. Places are a door, a window, a piece, or "e n". |
| `set` | Set a room setting: exposure, daylight, bulb, bounces, size (pixels). |
| `element` | (internal) the element form of "make": make a paper \| card \| piece \| plate \| sheet called … from <body>, W by H, at X Y. |
| `slam` | Slam an element down onto the stage at a time, like a rubber stamp: "slam the sell-stamp in at 7 s." |
| `remove` | Take an element off the stage at a time: "remove the title at 4 s, to the left." Or in place: shrinking, fading or sinking. |
| `fade` | Fade an element in or out over time: "fade in the title at 1 s, over 0.5 s." "fade out the title at 4 s, over 0.4 s." |
| `float`, `pulse`, `sway`, `bob`, `breathe`, `rock` | Motion that keeps going for the whole video: "float the badge, 14 high, every 3 s." "pulse the button, by 0.06, every 1.2 s." "sway the tag, 5 degrees, every 2 s." A wheel that keeps turning: "turn the wheel, every 4 s." |
| `glide` | Move an element (or the camera) to a new place over time: "glide the chart to 540 700, turned 3, at 9 s, over 0.6 s." "glide the camera to 700 600, zoom 1.2, at 9 s, over 0.5 s." The motion eases in and out unless you add: linear, ease-in, ease-out, overshoot, bounce or elastic. |
| `caption`, `say` | A caption that appears word by word: caption "TEXT" at T s, for D s, "keyword" in #colour. |
| `style` | Caption style: "style the captions in Jost, size 62, #1d1b18, at 1560." |
| `reveal`, `show` | Reveal a layer over time, as if drawn or written: "reveal the price at 5 s, over 3 s, from the left." |
| `bring`, `send` | Change stacking: "bring the memo to the front", "send the seal to the back", "send the seal behind the memo". In a video, "bring in the memo at 1 s, from the left" makes an entrance; instead of a side it can arrive popping, rising, zooming or fading. |
| `mix` | Mix a paint from pigments (Kubelka-Munk, like real paint): parts, "a touch of", "a little"; then a finish. |
| `let` | Brings a thing into being: "Let there be a flat canvas called poster, 1080 by 1350." "Let there be a circle called sun, 330 big, at 800 330." Several at once, instead of a loop: "Let there be 9 circles called orbit, at 540 560, the first 70 big, each 70 bigger than the last.", "… in a row, 46 apart", "… in a grid 8 by 5, 46 apart, from 70 70", "… in a ring around 540 560, 450 out", "each turned 30 more". Afterwards "the orbits" means all of them, and "the third orbit", "the last orbit" or "every other orbit" picks some. Also names a value: "Let gold be #ffb347." Layout: "Let the margin be 120.", "Let text be in Jost, size 26, aligned left.", "Let a heading be Martian Mono, size 26, tracking 6, brass." Things can be placed when they are made ("…, under the heading, 40 apart", "…, pointing right, in the play"). A table: "Let there be a table called playlist, 1436 by 448, at 800 650, 8 rows, columns at 28, 78, 818 and 1398 right, in Jost, size 24." |
| `make` | Applies a known word to a thing. A colour or material: "make the card #10131f", "make the title gold". An effect: glow, shadowed, outlined, frosted, grainy, vignetted. A state: grayscale, blurred 6, 40% see-through, uppercase. A transform: bigger, 780 wide, turned -24, flipped, line up on the left. A motion (video): float, pulse, sway, spin, fade in. Details follow as commas, and several words can share a sentence: "make the title gold, shadowed and uppercase." (Also shapes a zone: "make the window 756 by 1345.") |
| `give` | Gives a thing something it has: "give the title a shadow, 10 down, blur 14", "give the card the colour #10131f", "give the card a vignette of 0.35". Also sets one value: "give the title a size of 170", "give the glow a width of 90" (width, blur, strength, colour, opacity). |
| `move` | Puts a thing somewhere else: "move the badge to 540 300", "move the badge 40 right, 20 down". With a time it travels there (an object in a video): "move the ball to 880 300 over 1.4 s, bouncing" (bouncing, elastic, overshooting, linear, ease-in, ease-out). Or by words: "move the badge under the title, 20 apart", "move the badge in the panel, at the top right, 16 in". |
| `change` | A change over time, for an object in a video: "change the title to invisible over 0.5 s", "change the badge to 120% size for 0.5 s, then back", "change the tag to turned 20 over 1 s". States: visible, invisible, N% size, N times bigger, turned N. "for N s" holds it and returns; "then back" returns after a moment. Use "move" for place. |
| `when`, `once`, `after` | An event in a video: the rest of the sentence happens at that moment. Moments: "the video starts", "the video reaches 2 s" (or "after 2 s"), "the video ends", and what an object does: "the ball arrives" (its move ends), "the title appears", "the title leaves". Chain them, so nobody adds up seconds. |

## Engines

Engines read the document, never the source. "web" is the one renderer the app uses (WebGL2 in the browser, live light); "svg" exports flat vectors; the others are kept for older pipelines.

| Engine | What it makes |
| --- | --- |
| `fancard-py` | Fancard v1 · reference only (Python factory): Runs the locked v1 factory: metals, relief, enamel and light, as a tilt-and-flip card page. About 30–90 s. |
| `room` | Room (Mitsuba): Interiors: builds the room and renders every photographed shot with the Python path tracer. |
| `svg-preview` | SVG preview · instant: Pure JS, under a second. Flat metals and enamel, masks, photo and sprays. For drafting. |
| `svg` | Vector export (SVG): One SVG file of a card or canvas: flat colours, gradients, shadows, glows, photos and text. Relief and sprays are left out. |
| `web` | Web renderer (live light, WebGL2): Builds each face of each element in the browser and lights it live. One renderer for cards, canvases, stages and videos. |
